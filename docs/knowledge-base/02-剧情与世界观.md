# 02 - 剧情与世界观

> 数据更新至：2026年8月（含《命运传奇》全部剧情）

## 1. 核心设定

- **旅者（The Traveler）**：一颗神秘白色星球状存在，为人类带来"黄金时代（Golden Age）"，随后在"崩塌（The Collapse）"中滞留地球上空，庇护最后之城。
- **光（Light）**：来自旅者的力量，用于复活守护者、赋予三大元素技能与不死之身（"守护者"即被光复活的不死战士）。
- **暗（Darkness）**：与光对立的原始力量，包含"见证者（The Witness）"与"终焉之形"的哲学。守护者亦可驾驭暗影元素（冰凝 Stasis、缠丝 Strand、以及"终焉之形"后新的能力体系）。
- **幽灵（Ghost）**：由旅者碎片形成的智慧单位，负责复活与辅助守护者，是每个守护者的伙伴。
- **守护者（Guardian）**：被光复活的战士，隶属"先锋（Vanguard）"，守护人类最后之城（The Last City）。
- **见证者（The Witness）**：光与暗传奇的最终反派，希望以"终焉之形"让宇宙归于寂静。

## 6. 主题与哲思

- 光与暗并非简单的善恶二分；见证者代表"寂静与终结"，守护者代表"变革与生命"。
- 命运传奇以"预言、选择、背叛、边境法则"为主题，更强调玩家驱动的非线性叙事与盟友关系的权重。
