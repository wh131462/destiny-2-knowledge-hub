# 05 - 武器系统

> 数据更新至：2026年8月（含《宿命边缘》《叛逃者》新武器原型）

## 1. 武器槽位与类型

《命运2》共可装备 **3 把武器**（动能/能量/重型），外加近战与手雷。

| 槽位 | 说明 |
|------|------|
| 动能槽（Kinetic） | 多为实弹，部分为"停战"（Stasis/Strand）元素 |
| 能量槽（Energy） | 携带光能元素（Solar/Arc/Void） |
| 重型槽（Power） | 火箭筒、机枪、刀剑等重火力 |

## 3. 词条（Perk）系统

- **枪管/弹匣（Barrel/Magazine）**：影响后坐力、射程、稳定、装填等基础属性。
- **主词条（Perk 1）**：常见如"快速拔枪""精准计策"等。
- **副词条（Perk 2）**：常见如"狂热者（Rampage）""杀戮之风（Killing Wind）""亡命之徒（Outlaw）"等。
- **起源特质（Origin Trait）**：厂商/活动专属被动（2022年起）。
- **多功能模组插槽**：追踪、瞄具、弹药模组等。
- **2025 后：武器分层（Weapon Tiers）** ——《宿命边缘》引入武器分级系统，高等级武器拥有更强基底与更多词条位。

## 4. 武器锻造（Weapon Crafting）

- 来源：邪姬魅影（2022）。
- 玩法：通过"红色边框（Deepsight）"武器积累进度 → 解锁锻造配方 → 在锻造台制作，可**自定义每一列词条**并升级武器等级解锁更多词条位。
- 命运传奇时代仍可使用；部分旧武器通过"记忆碎片"等方式解锁。

## 5. 异域武器（Exotic Weapons）

- 每把异域武器拥有**唯一特效（Exotic Perk）**，不可替换。
- 经典异域举例：
  - 加拉尔号角（Gjallarhorn，狼群火箭筒，命运1复刻）
  - 雷神（Thunderlord，机枪）
  - 神圣裁决（Divinity，团队辅助追踪步枪）
  - 黑桃A（Ace of Spades，凯德-6的手炮）
  - 荆棘（Thorn，毒素手枪，德雷根·约尔遗物）
  - 碎愿者（Wish-Ender，可穿透目标的弓）
  - 极星长枪（Polaris Lance，烈日斥候步枪；不要与北极星 Lodestar 混淆）
- 异域催化（Catalyst）：完成特定条件后解锁额外加成。

## 7. 弹药与补给

- 主弹药（Primary）：无限/自动补充。
- 特殊弹药（Special）：击杀掉落（2022年起改为击杀产生）。
- 重型弹药（Heavy）：通过击杀与弹药箱获取。
- 弹药搜寻/储备模组可提升掉落率与容量。

## 8. 2025–2026 武器相关更新要点

- **宿命边缘（Edge of Fate）**：武器分层（Weapon Tiers）上线，护甲3.0同步调整；新增多种新词条与厂商（含艾欧尼安 AION 主题武器）。
- **叛逃者（Renegades）**：
  - 新增武器原型 **爆能枪（Blasters）** 与 **十字弓（Crossbow）**。
  - 引入"武器悲哀（Weapons of Sorrow）"系剧情联动武器。
  - 新增"普拉希克（Praxic）"主题武器。
- 传统赛季武器通过《过往赛季纪念碑（Monument to Seasons Past）》获取（灰烬与钢铁更新起）。
