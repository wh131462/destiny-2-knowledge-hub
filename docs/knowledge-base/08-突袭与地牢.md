## 3. 突袭/地牢奖励

- **首次通关**：高光等装备 + 成就。
- **异域武器**：多数突袭/地牢隐藏"异域任务"或异域掉落（例：DSC 的 Divinity、GoS 的 Divinity、预言地牢的 DMT 复刻等）。
- **传说套装**：每座突袭/地牢拥有专属传说护甲套装与武器。
- **徽章/称号**：完成挑战解锁（如"征服者"等）。

## 4. 2025–2026 新动态

- **永恒荒漠（The Desert Perpetual）**：
  - 2025-07-19 上线，竞赛模式世界首杀。
  - 2025-09-09《灰烬与钢铁》更新开放**史诗突袭（Epic Raid）**：扩展机制、新挑战、专属奖励。
  - 2026-07-08 更新（9.7.0.3）重新启用其中"无线系链"机制。
- **均衡（Equilibrium）**：唯一在《叛逃者》中推出的地牢（《叛逃者》是首个没有突袭的主线资料片）。

## 5. 匹配与组队

- 突袭：**不提供随机匹配**（需自组火力队或使用官方"火力战队搜索器（Fireteam Finder）"）。
- 地牢：默认不匹配；支持"地牢轮换"时可能开放。
- 官方推荐使用 Bungie 火力战队搜索器（App 内）寻找队伍。
