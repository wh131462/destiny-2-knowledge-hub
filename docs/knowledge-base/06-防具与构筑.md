# 06 - 防具与构筑

> 数据更新至：2026年8月（护甲3.0、装备分层时代）

## 1. 护甲部位与职业

| 部位 | 通用名 | 职业专属 |
|------|--------|----------|
| 头盔 | Helmet | — |
| 臂铠/手套 | Gauntlets / Gloves | — |
| 胸甲 | Chest Armor | — |
| 腿甲 | Leg Armor | — |
| 职业装备 | Class Item | 泰坦=徽章（Mark）；猎人=披风（Cloak）；术士=臂环（Bond） |

- 每件护甲有**属性（Stats）**与**模组槽（Mod Slots）**。
- 稀有度：普通→优秀→稀有→传说→异域（同武器体系）。

## 2. 护甲 3.0（2025，宿命边缘）

《宿命边缘》对护甲系统进行全面重做，称为 **护甲 3.0（Armor 3.0）**：

- **装备分层（Gear Tiers）**：护甲与武器均引入分级（Tier），更高层级拥有更强属性上限与更多模组位。
- **属性整合**：六维属性（机动/韧性/恢复/纪律/智慧/力量）保留，但加成规则重做。
- **模组系统重构**：新模组体系更强调"套装协同"与活动针对性。
- **套装加成（Set Bonuses）**：同一套装的多个部位可激活额外加成（如"权利的真相"套装——2026年6月17日更新 9.7.0.1 中修复了其加成问题）。
- **幻化系统**：外观装备（Ornament）与"合成纤维（Synthweave）"解锁装扮。

## 3. 模组（Mods）体系

- **头盔**：瞄准/弹药/超能力模组
- **臂铠**：近战/装填/武器拾取模组
- **胸甲**：抗性模组（对特定伤害类型减伤）
- **腿甲**：弹药储备/移动模组
- **职业装备**：技能充能/终结技模组
- **季节神器（Seasonal Artifact）**：每赛季提供独特被动模组，参与构筑。

## 4. 异域护甲（Exotic Armor）

- 每职业数十件，每件提供**唯一被动**，通常与某元素/某玩法强协同。
- 经典举例：
  - 泰坦：世界之心（Heart of Inmost Light）、狮心（Cuirass of the Falling Star）
  - 猎人：星云之眼（Star-Eater Scales）、龙之影（Dragon's Shadow）
  - 术士：星界协议（Starfire Protocol）、尼欧塔瑞之刃（Necrotic Grips）
- 异域护甲可装备**1件**（与异域武器冲突选择）。
- 2025 起部分异域获得"异域护甲3.0"重构（适应性更强、模组位更统一）。

## 5. 护甲获取来源

| 来源 | 说明 |
|------|------|
| 活动掉落 | 打击/行动、突袭、地牢、熔炉、智谋 |
| 异域档案（Xûr） | 每周五–周一出售随机异域 |
| 失落区域（Lost Sector） | 高难度单人可掉落指定部位异域 |
| 传说大师卷（Master/Grandmaster） | 高难活动保底高属性护甲 |
| 锻造/纪念碑 | 部分旧内容解锁 |

## 6. 构筑（Build）思路

### 6.1 属性优先顺序（通用参考）
- **韧性（Resilience）**：2025-2026 版本通常优先堆到 100（减伤最高档）。
- 其次视职业：猎人偏机动、术士偏恢复。
- 技能循环职业堆纪律/智慧/力量到 100。

### 6.2 常见构筑流派（2025–2026 环境）
- **泰坦**：虚空哨兵"气泡+堡垒"辅助流；炽阳破日者"灼烧循环"流；缚丝巨兽"压制冲撞"流。
- **猎人**：电弧"拳师+浪人"近战流；虚空"隐身侦察"流；缚丝"爪钩机动"流。
- **术士**：炽阳黎明刃"治疗/增伤光环"流；虚空"新星爆发"流；缚丝"织网召唤"流。

### 6.3 装备分层与套装协同（新）
- 优先装备 **Tier 高**的护甲（属性总值高）。
- 关注**套装加成**：凑齐2/4/6件获得更强效果（例：《叛逃者》"权利的真相"套装的加成）。
- 用异域件替代套装中属性最差的一件，最大化收益。

## 7. 记忆碎片与幻化

- **幻化（Transmog）**：通过"合成织物"将任何护甲外观解锁为装扮，覆盖当前装备外观。
- 解锁进度来自每周限定数量的护甲合成任务。

## 8. 2026 现状提示

- 最终更新《凯旋纪念碑》未引入新套装，主要提供回顾性内容与奖励。
- 周期事件（至日等）会提供限时高属性护甲，适合补齐构筑。
